# Portal

The IDEViewer portal is a self-hosted web dashboard for monitoring IDE security posture across your organization. It aggregates scan data from all registered machines and provides search, filtering, alerts, and CSV export.

| Page | What it covers |
|------|----------------|
| [Dashboard](dashboard.html) | Fleet overview, risk summary, recent activity |
| [Host Detail](host-detail.html) | A single machine: liveness, inventory, findings, SBOM export, on-demand scan |
| [Search](search.html) | Cross-fleet search over extensions, packages and hosts |
| [Integrations](integrations.html) | Webhooks, the event catalogue, Prometheus metrics, background jobs |
| [Administration](administration.html) | Accounts, sign-in options, roles, customer keys, host tokens, audit log, transport security |
